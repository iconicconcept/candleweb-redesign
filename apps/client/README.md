## How to run it

First you will need pnpm to run the project

```bash
npm i -g pnpm
```

Install the required packages by running:

```bash
pnpm i
```

Then run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The env file is already present in the repo and can be used
